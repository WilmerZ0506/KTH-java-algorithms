# KTH-java-algorithms
Object-oriented algorithms, custom data structures, and graph traversal projects built in Java.

Practical implementations of advanced data structures, object-oriented design patterns, and graph algorithms developed during KTH studies.

Technologies Used
* Java (Standard Library, Collections, Generics, JUnit-tested logic)

Key Modules & Features
* Graph Pathfinding (RoadGame): Implemented Breadth-First Search (BFS) using Queue and LinkedList on a 2D grid for path validation and win-state checking in a turn-based board game.
* Automated Scheduler (StudentScheduler): Developed an object-oriented data model utilizing the Comparable interface for multi-level sorting (by date, last name, first name) and custom grouping logic.
* Optimized Algorithms (MaxSequens): Solved sequence and optimization problems in O(n) time complexity using the Sliding Window technique with a HashSet.
